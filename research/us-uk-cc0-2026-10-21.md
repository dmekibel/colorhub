# US/UK CC0 painting staging, 2026-10-21

Staged in `data/corpus-staging/zz-museum-<source>-<n>.json` on branch `staging/us-uk-cc0`. Nothing in `data/corpus` or `data/gallery` was touched, and no images were downloaded. Every row has `license: "CC0"` and a `url` to the museum's own record. Duplicates were removed by id (`nga-<objectid>`, `walters-<ObjectID>`, `saam-<object number>`) and by artist+title+year twin against all rows in `data/corpus`. Rows with no named artist skip the twin test.

## Method
- **NGA:** same filter as `tools/museums/nga.py`: classification Painting, not virtual, primary image with `openaccess=1`. The 202 are paintings the earlier build left out. They are mostly twins that were removed, plus items added to the open data since the last pull.
- **Walters:** `art.csv`, `media.csv` and `creators.csv` from the `WaltersArtMuseum/api-thewalters-org` repo. Kept objects whose ObjectName contains "painting". Dropped miniatures, folios, albums, manuscripts and books.
- **SAAM:** the Smithsonian Open Access S3 shards for unit SAAM (`metadata/edan/saam`). Kept Type=Painting with metadata and media access both CC0. Image URL is `ids.si.edu/ids/deliveryService?id=<idsId>&max=400`.
- **Titles and dates:** titles are whitespace-cleaned and truncated at 90 characters, as `corpus.py` does. Dates use `common.year_span`. Years outside 1100–2026 are dropped.
- **Country:** `co` comes from `COUNTRY_RULES`, and is null when unknown. SAAM names a nationality only for non-Americans, so a SAAM artist with no nationality is mapped to the United States.

## Doubts
- **Walters images:** `img` is the full-size file `art.thewalters.org/images/raw/...`, not a 400 px thumbnail. I did not check that a smaller size exists. The host was not reachable from this session, so the coordinator should check the URLs download.
- **Walters scope:** some Walters rows are Asian scroll or thangka paintings, and about 25% have no artist. A few rows keep a school or place name as the artist (for example Ferrara, Parma, Marchigian) that should be nulled.
- **Walters CC0:** the Walters CC0 grant is stated in its repo README for all data and images. I did not check it object by object.
- **SAAM CC0:** access is checked per record and per image. Some titles are generic ("Untitled", plant studies), and some are studies or watercolors. `ids.si.edu` is also not reachable from this session.
- **SAAM artists:** the artist is parsed from the free-text name field, so a few odd names may remain.
- **NGA:** the 1,522 paintings without an open-access image are excluded, because the image terms are not CC0.
- **Excluded by instruction:** Royal Collection, National Trust, Tate. Harvard was skipped as instructed.
