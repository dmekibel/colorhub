# ColorHub

Learn the names of colors, one family at a time. A placement test, then short units: meet about 8 colors beside their nearest neighbors, name them in a swipe deck, and review them over the following days.

**Live:** https://dmekibel.github.io/colorhub/

- No build step. Open `index.html` through any static server (`node tools/serve.js`).
- Curriculum data: `data/colors.js`. Run `node tools/check.js` after editing it.
- Design decisions and sources: `DESIGN.md`. Product plan: `PLAN.md`. Current status: `HANDOFF.md`.

Hex values are screen approximations drawn from the CSS named colors, Wikipedia's list of colors and the xkcd color survey.
